# Dataset source and attribution

This project includes the **Bike Sharing** dataset from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset).
The `raw/` directory contains the original `day.csv`, `hour.csv`, and `Readme.txt` files.

- **Dataset page:** https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset
- **DOI:** https://doi.org/10.24432/C5W894
- **License:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
- **Original creator attribution:** retained in the dataset's accompanying `raw/Readme.txt` and the official UCI dataset page, without changes.

The data cover Capital Bikeshare in Washington, D.C., for **2011–2012**. They are historical and should not be treated as representative of current bike-sharing usage without further validation. The dataset license does **not** automatically apply to the analysis code.
